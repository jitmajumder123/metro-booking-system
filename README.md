# Metro System

Spring Boot & Thymeleaf metro management project.

## Features

- User registration and login using HTTP session
- Station list
- Route search
- Ticket booking
- Smart card creation and recharge
- Admin page to add stations and routes
- MySQL in-memory database with sample data

http://localhost:8080
